## 1. ART ENGINE — Complete Style System (9 Unique Renderers)

### What Was Built
Each style is a full Python renderer in `art_engine/styles/` that procedurally generates unique artwork from real match data (ball trajectory, pass chains, shot locations).

| Style | File | Creative Direction |
|-------|------|--------------------|
| Street | `street.py` | Spray paint graffiti — brick wall texture, drips, overspray, fat cap strokes |
| Jackson | `jackson.py` | Jackson Pollock — drip painting, chaotic layered paint, flowing bezier curves |
| Geometric | `geometric.py` | Voronoi tessellation — stained glass crystal shatter, mathematical precision |
| Marble | `marble.py` | Italian marble — polished stone veining, branching fractal veins |
| Smoky | `smoky.py` | Ethereal coloured smoke — atmospheric fog trails, gaussian blur layers |
| Futuristic | `futuristic.py` | Spiderweb — radial silk web with dewdrops, organic beauty |
| Camo | `camo.py` | Military camouflage — organic team-colour blobs, tactical dataline |
| Classic | `classic.py` | Vintage 1960s sports poster — halftone dots, Art Deco borders |
| Dalí | `dali.py` | Salvador Dalí surrealist — melting, warping, dreamlike distortion |

### Technical Architecture
- Base class: `art_engine/styles/base.py` — `Palette`, `DataLine`, `BaseStyle` types
- Registry: `art_engine/styles/__init__.py` — `get_style(name)` factory
- Bridge: `art_engine/api_generate.py` — routes API calls through new style system
- **Critical bug fixed:** Palette bridge was using list indexing on a dict → silent fallback to old renderer

### Key Files
- `art_engine/styles/*.py` — 9 style renderers (~200-400 lines each)
- `art_engine/line_effects.py` — 6 dataline effects (568 lines)
- `art_engine/api_generate.py` — main generation pipeline (~1200 lines)

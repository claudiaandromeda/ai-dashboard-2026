### Art Engine — Path Override Data Format (DOCUMENTED)
- Coordinate system: **normalised 0.0–1.0** (NOT StatsBomb 120×80)
- Convert from StatsBomb: `x_norm = sb_x / 120.0`, `y_norm = sb_y / 80.0`
- Format: `[(x_norm, y_norm, event_type), ...]` — flat ordered list, earliest first
- Event types: `"pass"`, `"carry"`, `"shot"`, `"goal"`
- API: pass `pathOverride` array in POST body to `/api/art/generate`
- Engine smooths with spline interpolation — 10–25 events ideal
- Goal point = tessellation impact anchor; shot events curve toward goal
- Player IDs, timestamps, team NOT consumed by current engine

## Configurator Overhaul — Diagnostic Complete (12:30 GMT)

### Broken Slider Root Cause — FOUND
The new style system (`art_engine/styles/*.py`) does NOT receive `bgDetail`, `bloom`, `intensity`, or `edgeVisibility`.
- `render_background(draw, image, palette)` — no density/detail params passed
- `render_data_lines(draw, image, data_lines, palette)` — no intensity params
- Only the OLD styles (pebbles, broken_glass, spider_web, honeycomb) use these params
- ALL 9 current styles (classic, geometric, camo, futuristic, street, marble, smoky, jackson, dali) use the NEW system

**What each slider actually does:**
- `Glow Intensity` (frontend) → `bloom` (art server) → WORKS on data line glow layer (controls radius + falloff)
- `Pattern Density` (frontend) → `bgDetail` → `bg_density` → NOT PASSED to new style renderers — BROKEN
- `Line Thickness` (frontend) → `edgeVisibility` → `edge_vis` → NOT PASSED to new style renderers — BROKEN
- `Contrast` (frontend) → `intensity` → scales glow layer alpha — WORKS but misleadingly named

**Brightness** (in "Pattern on Garment" section) → `textureControls.brightness` → THREE.js shader uniform, NOT art server — this is a post-processing 3D viewer effect

### Frontend → Art Server Param Mapping
```
Frontend                → body.field      → art_server param    → Effect
────────────────────────────────────────────────────────────────────────
Glow Intensity (0-100)  → bloom           → bloom               → Data line glow radius/falloff ✅
Pattern Density (0-100) → bgDetail        → bg_detail→bg_density → Old styles only, new styles IGNORE ❌
Line Thickness (1-5)    → edgeVisibility  → edge_vis            → Old styles only, new styles IGNORE ❌
Contrast (0-100)        → intensity       → intensity            → Scales glow alpha (not contrast) ⚠️
Brightness (0.4-2.0)    → N/A             → THREE.js uniform     → 3D viewer shader effect ✅
```
